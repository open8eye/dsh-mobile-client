# 连接指南

本文覆盖从「电脑上什么都没有」到「手机上打开 DSH」的每一步，以及连不上时怎么查。

## 一、电脑端

### 1. 确认 dsh web 在跑

DSH 的 Web 服务只监听 `127.0.0.1:3080`，**这是官方刻意的安全设计**：
它没有认证，直接对外等于把「能执行代码的 agent」裸奔。

所以手机永远不该连 3080，而是连 dsh-pocket 的 **3081**。

### 2. 确认 dsh-pocket 在跑

桌面版：**设置 → 手机访问**。页面上应该能看到：

- 「局域网访问」开关（默认开）；
- **📶 局域网二维码**与局域网密码；
- 「开启公网访问」按钮。

如果看不到这个页面，说明插件没装好。

### 3. 建议：把局域网密码设成固定的

点局域网区块的「自定义」，设一个 8 位密码（字母 + 数字）。
自定义之后密码不再轮换，App 才能一直靠它自动登录。

> 如果你只用同一 Wi-Fi 且不在意安全，也可以把「局域网访问密码」开关**关掉**，
> 那样局域网扫码直连、完全不需要密码。
> **但公网密码始终必需**，关不掉。

## 二、手机端

### 扫码（推荐）

1. 底部导航栏 → **扫一扫**；
2. 对着电脑屏幕上的**局域网二维码**；
3. App 预填地址 → 填**访问密码** → 保存；
4. 直接进入 DSH。

### 手动添加

底部导航栏 → **设备列表** → 右下角 **+**，或扫一扫页面的「手动添加设备」：

| 字段 | 说明 |
|---|---|
| 服务器地址 | `http://192.168.1.5:3081`（**必须带端口**，代理端口可能是 3081–3091 中任意一个） |
| 设备昵称 | 随便取，会显示在导航栏上 |
| 访问密码 | 电脑上「手机访问」页面显示的那 8 位 |

### 扫描分享链接

如果你把 `http://IP:3081/?token=<密码>` 这样的链接做成二维码，App 扫到后会
**连密码一起存下来**，不需要手输。

## 三、Tailscale（出门在外）

1. 电脑、手机都登录同一个 Tailscale 账号；
2. 电脑上「手机访问」→ 局域网区块 → **「局域网地址」下拉框**选 `100.x.y.z`；
3. 手机 App 连 `http://100.x.y.z:3081`，密码用**局域网密码**。

原理：dsh-pocket 把 CGNAT `100.64.0.0/10` 归类为局域网，
所以 Tailscale 地址走的是局域网密码那条分支。

> 为什么不用公网隧道？公网入口会把 DSH 暴露到互联网，
> 而 Tailscale 只在你自己的 tailnet 内可达，更安全也更稳定。

## 四、排障

| 现象 | 原因与处理 |
|---|---|
| 一直停在「需要访问密码」 | 密码不对，或电脑上点过「刷新」换了新密码。到设备列表里编辑该设备重填 |
| 提示「连接失败」 | 检查：电脑上 `dsh web` 和 dsh-pocket 是否都在跑；手机和电脑是否同一网络；端口对不对 |
| 局域网能连、Tailscale 不能 | 电脑上「局域网地址」下拉框没选 Tailscale 地址；或手机没登录 Tailscale |
| 页面白屏 | 电脑上 dsh-pocket 的 advanced 模式不支持手机访问，切回 compatibility 后重启 |
| 二维码扫不出 | 手机摄像头权限被拒（去系统设置里开）；或把地址手动敲进去 |
| 桌宠开关打不开 | 需要「显示在其他应用上层」权限；授权后回到 App 再开一次 |
| iOS 上桌宠不可用 | 正常。iOS 不允许第三方 App 覆盖桌面 |

## 五、安全提醒

- DSH 能在你电脑上执行代码。**二维码、地址、密码都不要发给别人**。
- 密码泄露了：电脑上「手机访问」→ 点「刷新」换新密码，然后在 App 里更新。
- 公网访问用完就关。
- 涉密 / 公司网络请先确认合规再用公网隧道。
